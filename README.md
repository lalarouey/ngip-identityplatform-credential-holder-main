# Decentralized Identity Platform - Credential Holder

This project is part of the Decentralized Identity Platform and serves as the Credential Holder component.

## Features

- Handles DID management for users of the platform.
- Integrates with other components of the platform ecosystem.

## Prerequisites

- Docker
- Docker Compose

## Running the Project with Docker Compose

Follow these steps to run the project using Docker Compose:

1. Clone the repository:

```bash
git clone https://github.com/NTNU-IDI/ngip-identityplatform-credential-holder.git

cd ngip-identityplatform-credential-holder
```

2. Build and start the services:

```bash
docker-compose up --build -d
```

3. Access the application:

- The service will be available at `http://localhost:5173` (Unless the configured port in `docker-compose.yml` is updated).

4. To stop the services:

```bash
docker-compose down
```

## Configuration

- Update the environment variables in the `.env` file as needed.
- Modify the `docker-compose.yml` file to customize service configurations.

## Example `.env` File

Below is an example of the `.env` file for the backend configuration:

```env
#Veramo settings
# Can be generated by running 'generateKey' in backend
KMS_SECRET_KEY=123456789

#RPC Provider API Keys
INFURA_PROJECT_ID=123456789
ALCHEMY_API_KEY=123456789

# Database configuration (we use Pinata for IPFS)
PINATA_JWT=123456789
GATEWAY_URL=123456789

CREDENTIAL_HOLDER_URL=http://holder-agent:3002
```

Make sure to replace the placeholder values with your actual configuration.
